## 상호작용 명세 (source에만 있는 동작)

### ChatWidget
- 상태: `closed`(일동이 idle 영상 + 말풍선 "무엇을 도와드릴까요?") → 클릭 → `open`.
- 런처는 `<button aria-label="일동이와 채팅 열기">`, 영상은 `aria-hidden`.
- 열림: 헤더(hello 아이콘, 이름, 연결 상태, 전체 화면, 닫기) / 첫 화면 wave 영상 + 인사 + 예시 요청 3개.
- 예시 클릭 → `thinking`(thinking 아이콘 + 4단계: 내용 정리 → Jev 판단 → 업무 나누기 → 결과 저장) → `result`.
- 결과 아이콘: 자동 처리 가능 = like, 확인 필요(검토) = surprised, **긴급 = 마스코트 없음(빨간 경고)**.
- 매체 선택: 기본 webm, Safari = webp, `prefers-reduced-motion` = mascot.png.
- 520px 이하에서는 채팅창이 전체 화면이 됩니다.

### Observatory 재생
- 재생은 **저장된 기록 조회**만 합니다. 모델 재호출이나 재배정을 하지 않고, "새 실행으로 다시 처리"는 별도 버튼입니다.
- 단계 0~8 + 9(전체 결과). 재생 중 이전 단계 = 최종 상태, 현재 단계 = 진행 중(오렌지 후광), 이후 단계 = 대기(점선).
- 병렬 노드(추출 ×4, Jev ×4)는 같은 단계에서 동시에 시작합니다.
- 실패 노드는 실패로 끝나고, 사람 대기 구간은 압축하되 실제 대기시간을 표시합니다.
- 속도 0.5×/1×/2×/4×, 구간 바 클릭으로 이동, 노드 클릭으로 Trace 상세(실행·단계 ID, 시각, 소요, 입출력, 근거, 오류·재시도, 정책·모델·스키마 버전)를 엽니다.
