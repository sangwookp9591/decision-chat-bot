# 제품 동작 계약

이 문서는 `docs/spec/`에 별도 수락 문구가 없는 현재 구현 동작을 설명한다. 명세의 완료 판정을 대신하지 않는다.

## 분석 취소

요청 작성자와 operator만 실행 중 또는 대기 중인 Run을 취소할 수 있다. 브라우저는 세션 쿠키와 CSRF 토큰을 포함해 `POST /api/requests/{request_id}/runs/{run_id}/cancel`을 호출한다. 서비스는 Request, Run, Job의 tenant 범위와 작성자/operator 권한을 확인하고 취소 시각·행위자·현재 단계를 보존한다. 취소는 멱등이며, 이미 판단이 저장된 Run에는 `judgment_saved`를 반환한다. worker의 lease generation을 올려 늦게 도착한 결과 커밋을 차단한다. `backend/tests/integration/test_cancel_run.py`는 서비스 경합·권한을, `test_cancel_http.py`는 HTTP 세션·CSRF·상태 코드 경계를 검증한다.

## ChatGPT식 대화 접수

요청 작성은 대화 화면에서 이루어지며 작성자의 말풍선, 비동기 분석 단계, 일동이의 응답 및 결과를 한 요청 대화로 표시한다. 오류가 있는 첨부는 실패 파일과 다음 선택을 대화 안에 남기며, 보완 답변은 같은 요청의 새 revision이 된다. 대화 화면은 기존 요청을 다시 열고 저장된 진행/결과를 복원한다. UI의 즉시 말풍선은 낙관적 표시일 수 있으므로 서버 저장 확인은 요청 목록/진행 이벤트/최종 상태로 한다.

## 잠정 판단

분석이 길어지면 일부 단계가 끝난 판단을 잠정 결과로 먼저 표시할 수 있다. 이는 최종 판단 저장 및 완료 상태와 구별되며, 최종 결과가 도착하면 잠정 표시를 대체한다. 잠정 결과는 업무 배정이나 승인 근거로 취급하지 않는다. 재시도·취소 시 해당 Run의 상태와 최종 결과를 다시 조회해 화면을 맞춘다.

## 목록 제목·미리보기 권한

요청·검토 목록의 제목은 저장된 안전한 preview projection에서 제공한다. 제목/미리보기 허용 여부와 원문 열람 권한은 별개다. 원문 권한이 없는 사용자는 허용된 요약만 볼 수 있고 원문은 반환하지 않는다. 전체 원문 열람은 별도의 `can_read_source` 권한 검사를 거친다. API projection 및 역할별 권한 시험은 `test_api_preview.py`, `test_review_display.py`에서 관리한다.

## 평가 라벨 역할과 권한

labeler는 배정된 split의 제안 라벨을 확정하거나 근거를 적어 보류할 수 있다. reviewer는 독립 라벨을 제출할 수 있으며 라벨 차이는 합의가 필요한 불일치로 표시한다. 합의 라벨 확정은 합의 권한을 가진 역할에 한정된다. labeler의 화면 접근만으로 정책·학습 규칙 게시 권한을 부여하지 않는다. API의 역할 검사와 split 경계가 권한의 기준이며 UI 버튼 상태는 보조 표현이다.
