# 접근성·반응형 브라우저 검증

T23의 재현 가능한 브라우저 검증은 `frontend/e2e/a11y/a11y.spec.ts`와 `frontend/playwright.a11y.config.ts`에 있다. 실제 로그인 세션과 실제 API 데이터를 사용하며, 주요 화면의 axe 검사에서는 critical/serious 위반만 게이트로 취급한다.

## 실행

Neo4j, API, worker를 실행한다. E2E 전용 tenant를 만들고 개발 역할 계정을 준비한 뒤 worker에는 그 tenant만 전달한다. WebKit 브라우저 설치는 `cd frontend && npx playwright install webkit`으로 한다.

```sh
make up
cd backend
.venv/bin/python ../scripts/bootstrap_dev.py
.venv/bin/uvicorn jevtriage.main:app --host 127.0.0.1 --port 8147
```

별도 터미널:

```sh
cd backend
.venv/bin/python -m jevtriage.jobs.worker --tenant <E2E 전용 tenant>
```

프런트 검증:

```sh
cd frontend
E2E_API=http://127.0.0.1:8147 E2E_PORT=5281 npx playwright test --config=playwright.a11y.config.ts
```

기본 Playwright 설정도 Chromium과 WebKit 프로젝트를 제공한다. 테스트 계정 암호를 바꿨다면 `JEVTRIAGE_DEV_PASSWORD`에 지정한다. 전용 tenant의 로그인 계정도 `requester`, `reviewer` 역할별로 준비한다.

## 검사 범위

- 로그인 및 요청 접수, 검토, 업무, 실행 관찰, 판단 맵 입체/목록, 규칙 학습, 모니터링, 정책 화면의 axe WCAG 2.1 A/AA 검사
- ChatWidget 열기와 요청 제출의 키보드 조작, 모달 포커스 순환, Esc 닫기와 초점 복귀
- 판단 맵 목록의 화살표 이동과 Enter 선택, 실요청 제출 후 원문 근거 열기
- 사이드바 고정/상단 메뉴 전환과 가로 overflow: 1280/960/520/375px
- ChatWidget 520px 전체 화면, 대표 버튼·메뉴의 44px 터치 영역, Primary 버튼 글자색
- reduced-motion 정지 PNG, WebKit/Safari의 WebP 선택, 화면 내 디자인 샘플 문자열 및 mock 표시 확인

브라우저 검증 스크린샷과 실행 결과는 `artifacts/validation/t23/`에 보관한다. 실데이터에는 사용자 원문이 포함될 수 있으므로 저장하는 스크린샷은 실행 전용 tenant의 비민감 검증 요청으로 한정한다.

## UX-1 화면 동작 기준 (브라우저 탐색 P3-01~P3-13 수정)

- **로그인**: 이메일·암호 입력과 제출 버튼이 있으며 오류는 `role="alert"`로 한국어 안내한다(401 잘못된 정보, 429 시도 제한). 성공해도 URL을 바꾸지 않으므로 처음 요청한 경로가 그대로 열린다.
- **URL이 상태를 가진다**: 요청 접수 `/?request_id=`, 검토 `/review?request_id=|review_id=`(처리 완료 검토도 열림, 결정 버튼은 읽기 전용), 실행 관찰 `/observatory?request_id=&run_id=`. 새로고침·뒤로가기·공유 링크로 같은 대상을 복원한다.
- **정보 요청**: 요청 상태가 '보완 필요'이면 검토자의 사유·필요 정보를 표시하고 같은 요청의 새 revision으로 보완 제출한다(`expected_revision` 포함). 결과 배지는 요청 상태(보완 필요·반려됨·배정 완료)를 우선하고, 검토 결정 SSE(`review_decided` 등)로 갱신한다.
- **채팅 위젯**: 접수 화면에서는 `chat:request` 이벤트로, 다른 화면에서는 sessionStorage 후 `/` 이동으로 전달하며 접수 입력에 채우고 포커스·안내(`role="status"`)를 둔다. 위젯은 전송 후 닫힌다.
- **입력 방해 금지**: 정책 JSON 편집기는 필드별 원문 초안을 유지하고 마지막 유효 값만 설정에 반영한다. 모니터링 기간은 초안/적용을 나누고 빈 값·역순은 입력 오류로 안내하며 조회하지 않는다.
- **한국어 라벨**: 역할·상태·검토 동작·첨부 읽기 실패 사유·서버 오류는 `components/statusLabels.ts`의 `roleLabel`·`statusText`·`reviewActionLabel`·`attachmentReasonLabel`·`localizeError`를 공용으로 쓴다. 내부 코드는 '기술 상세'(`<details>`)에만 둔다.
- **375px**: 요청 화면은 입력을 목록보다 먼저 두고 상태 배지는 줄바꿈하지 않으며, 규칙 학습 카드는 grid `min-width:0`으로 가로 넘침이 없다.
