# 배포 전 검토

현재 구성은 개발·검증용이다. Docker Compose는 Neo4j Community 5.26.0을 로컬 포트에 공개하고, 애플리케이션은 개발 계정 bootstrap과 로컬 프로세스 구동을 사용한다. 이 구성만으로 운영 보안, 고가용성, 외부 백업 보관, 장애복구 목표를 충족한다고 볼 수 없다.

## 운영 전 확정할 사항

- 인증 공급자, 계정 수명주기, MFA/세션 정책 및 역할·조직 동기화
- 비밀 저장·회전·접근 감사 (Jev 및 Neo4j 자격 증명 포함)
- 외부 TLS 종단, 네트워크 경계, 업로드 저장소 권한과 암호화
- 원격 관측 저장소, 독립 watchdog/알림 수신자와 호스트 유실 경보 경로
- 데이터/원본/journal/metrics/백업별 보존 기간, 삭제와 백업 파기 규칙
- RPO/RTO, 복원 리허설 빈도와 복구 책임자
- 모델 외부 전송 고지·동의 및 허용 데이터 범위
- Neo4j edition·지원·업그레이드·백업 호환 정책

## 미검증 목록

이 저장소에서 운영 인증 공급자, secret manager, TLS/ingress, 원격 관측 수신, 원격 장애 알림, 호스트 전체 손실 복원, 보존/삭제 자동화, 장기 부하와 30일 운영 SLO는 검증하지 않았다. 로컬 운영 시 webhook은 선택 설정이고 실패 시 로컬 파일/표준 출력에 기록되므로 외부 수신 보장이 아니다. 운영 릴리스 전 위 의사결정과 환경별 검증 증거가 필요하다. 개발 게이트와 운영 G13은 [인수 조건](../spec/06_ACCEPTANCE.md)에서 별개로 판정한다.
