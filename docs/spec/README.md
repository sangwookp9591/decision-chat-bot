# Jev 기반 업무 분류 판단 플랫폼 개발 문서

웹 채팅으로 접수한 업무 요청을 분석하고, AI 적용 필요성·개발 가능성·긴급도·담당 조직을 판단하여 업무를 나누고 추적하는 플랫폼의 개발 의뢰서다. 결과뿐 아니라 실제 처리 흐름과 사람의 개입, 성공과 실패를 눈으로 확인할 수 있어야 한다.

이 문서 묶음은 **성과와 완료 조건을 고정하고 구현 방법은 열어 둔다.** 고성능 AI 개발 에이전트가 합리적인 설계와 기술 선택을 직접 수행한다. 화면 모양, 클래스 구조, API 경로, 작업 순서까지 일일이 지정하지 않는다.

## 우선순위와 해석

완료 판정은 `06_ACCEPTANCE.md`, 수치와 측정 정의는 `05_SLO.md`를 기준으로 한다. 나머지 문서는 의도와 경험을 설명한다. 예시 데이터·상태 이름·다이어그램은 구현 계약이 아니다.

필수 결과를 약화시키는 변경은 근거와 영향을 제시하고 제품 책임자의 승인을 받아야 한다. 라이브러리·내부 구조·화면 배치 등 결과를 유지하는 선택은 에이전트가 자율적으로 결정한다. 필수 기술의 실연동을 모의 구현으로 대체해 완료라고 보고하지 않는다.

## 확장 범위

기존 요청 접수·분류·검토·배정·관찰·Flow·Topology 기능과 안전 조건은 유지한다. [08_LEARNING_LOOP.md](08_LEARNING_LOOP.md)의 R19–R26에 따라 수정 이력 비교, 규칙 후보의 검토와 권한, 부작용 없는 섀도 검증, 제한적 규칙·컨텍스트 적용과 효과 관찰, 실제 관계 기반 판단 맵을 추가한다. 기존 게이트 G01–G12와 운영 G13을 유지하며 확장 게이트 X01–X10은 별도로 식별·보고한다. SLO 수치와 분모는 바꾸지 않는다.

## 현재 문서의 상태

작성일은 2026년 10월 2일이며, 2026년 10월 3일 확장 갱신했다. 이 묶음은 개발을 위한 요구사항이며, 실행 가능한 플랫폼이나 검증 완료 보고서가 아니다. SLO 수치는 제품의 초기 목표로 제안한 값이며 측정 결과가 아니다.

참고 이미지에서 관찰한 범위와 제품 사실 확인 여부는 [07_SOURCES.md](07_SOURCES.md)의 '참고 이미지(Deeptwin) 확인 범위'를 따른다. 이미지는 화면 개념 참고이며 해당 제품의 실제 구현·동작 확인이나 수치·이름·문구의 제품 예시 사용을 뜻하지 않는다.
