# 공식 자료와 확인 범위

확인일은 2026년 10월 2일이다. 아래는 기술 역할과 호환성 판단의 근거이며 API 접근·한국어 정확도·브라우저 동작·프로젝트 성능의 검증 결과는 아니다.

| 공식 자료 | 문서에 반영한 사실 |
| --- | --- |
| [TypeSafe AI 소개](https://docs.typesafe.ai/introduction) | Jev는 state와 typed questions에 대한 구조화된 판단 모델. Choice·Score의 confidence와 Noul의 확률은 다른 필드 |
| [TypeSafe AI](https://typesafe.ai/) | Jev가 확률과 신뢰 신호를 제공하고 애플리케이션이 자동 처리·검토 기준을 결정하는 역할 |
| [WebMCP 초안](https://webmachinelearning.github.io/webmcp/) | 2026년 9월 30일자 Draft Community Group Report. JavaScript 도구 노출 및 Document의 modelContext 정의. W3C 표준 아님 |
| [d3-zoom](https://d3js.org/d3-zoom) | DOM 비종속 확대·이동 동작으로 HTML, SVG, Canvas에 사용할 수 있음. 화면 조작 구현의 선택지 근거 |
| [Neo4j Cypher Manual: 가변 길이 경로](https://neo4j.com/docs/cypher-manual/current/patterns/reference/variable-length-paths/) | quantified path pattern 및 quantified relationship으로 가변 길이 경로를 질의할 수 있음. 실제 저장 관계 탐색의 선택지 근거 |

Jev의 속도·가격·정확도에 관한 홍보 수치는 이 프로젝트의 SLO 근거로 사용하지 않았다. Confidence를 업무 정답률로 취급하지 않는다. WebMCP 지원 여부와 호출 결과는 구현 환경에서 별도로 확인해야 한다.

FastAPI·Neo4j·SSE·Dynamic Config의 역할과 SLO 수치, 평가 목표, 입력 한도는 이 프로젝트를 위한 설계 요구 및 초기 제안이다. 특정 공급자가 보장하는 계약이나 공식 벤치마크가 아니다. 개발 에이전트는 구현 시점의 공식 문서·실제 의존성 버전·현재 프로젝트 규칙을 확인한다.

## 참고 이미지(Deeptwin) 확인 범위

확인일은 2026년 10월 3일이다. 사용자가 제공한 스크린샷 4장을 코디네이터가 직접 관찰한 시각적 내용과 실제 제품에 대해 확인한 사실을 구분한다.

| 자료 | 이미지에서 관찰한 내용 | 실제 제품에 대해 확인한 사실 |
| --- | --- | --- |
| 이미지 1 · 입체 계층 화면 | 어두운 배경에 위에서 아래로 기울어진 5개 판이 점선으로 연결됨. 판 제목은 근거·가설·판단·배포·업무 단계로 읽히며, 화면에 표시된 항목 수는 각각 18·7·8·6·11이다. 근거 판에는 인터뷰, 행 ID처럼 보이는 예, 고친 곳·차이·소유자의 말·탐구 답 설명이 있다. 가설 판에는 날짜·해결 먼저, 사과 한 번, 환불은 담당자처럼 보이는 문구와 수정 이유 추정 설명이 있다. 판단 판에는 C/G/J/X/W 같은 접두 표기 예와 현장 객체·규칙·판단·표현·점검·역할 설명이 있다. 배포 판에는 X/C 형식 표기, 그림자·제한 적용 설명이 있다. 업무 단계 판에는 답변 초안·분류·요약·문서 생성처럼 보이는 항목이 있다. 선택된 업무 단계는 강조되고 비활성 노드는 흐리다. 상단에는 v1–v4 버전 탭, 운영 중·검증 중 상태와 변경 요약 문장, 하단에는 71% 확대율·확대·전체 보기·크게 보기 조작이 보인다. | 확인하지 않음. 화면 이미지에서 읽히는 값·ID·라벨·설명은 실제 제품의 데이터나 기능 증거가 아니다. |
| 이미지 2 · 차이·가설 화면 | 단계 탭은 내 버전→차이→가설→탐구→판단 순서로 보인다. AI가 만든 파일과 사용자가 고친 파일의 업로드 또는 화면 내 편집 선택, 행별 추가·삭제 차이와 행 ID·분류 표시가 있다. 오른쪽에는 동의할 가설을 묻고 각 가설의 근거 두 곳과 출처 라벨(전문가 판단·표현 선호로 읽힘)을 보여 주며, 체크 후 판단 후보로 올리는 조작이 보인다. | 확인하지 않음. 가설 출처·근거 표시와 후보 생성의 실제 동작은 확인하지 않음. |
| 이미지 3 · 실행 흐름 화면 | 실행 중 7/11 단계, 경과 시간, 모델 호출 594/최대 52처럼 보이는 카운터, 딥트윈(AI)·도구·사람 레인, 노드별 시간 배지, 최대 3번 반복 묶음과 사람 결정 노드가 보인다. 끝남·진행·사람 확인 대기·멈춤·기다림 범례, 미니맵과 68% 확대 표시도 있다. 오른쪽 '지금 AI가 하는 일' 패널은 '적용할 판단 읽음 — 이 단계에 고정된 규칙'으로 보이는 단계와 실행 기록을 보여 준다. | 확인하지 않음. 호출 수·최대값·진행 상태나 규칙 고정 동작의 정확성은 확인하지 않음. |
| 이미지 4 · 채팅 입력 화면 | '입력 대기 · Claude Code · claude-sonnet-5 · 음성 인식 미설치'로 읽히는 상태 표시, 점 구 그래픽과 준비 안내, 예시 요청이 채워진 입력창, 보내기 전 브라우저에만 임시 보관되고 인스턴스에는 저장되지 않는다는 안내가 보인다. | 확인하지 않음. 표시된 도구·모델·음성 인식 상태, 저장·전송 동작 및 개인정보 처리 방식은 확인하지 않음. |

실제 제품에 대한 공식 자료 확인이나 제품 접근이 없으므로 Deeptwin의 실제 구현·데이터 출처·동작은 확인하지 않았다. 이 프로젝트가 참고하는 개념은 근거→가설→판단→적용→업무 단계의 5계층 입체 판단 맵, 원안과 수정 차이에서 가설을 다루는 흐름, 버전 상태 구분, 실행 단계가 고정된 규칙을 읽는 표시다. 이미지의 수치·이름·문구는 이 관찰 표에서 화면 판독 내용으로만 기록하며 복제 대상이 아니고 제품 데이터 예시로 사용하지 않는다.

화면 배치는 자유롭게 설계하고 실제 기록과의 연결을 검증한다. 위 기술 자료는 구현 선택지의 근거이지 의무가 아니다.
