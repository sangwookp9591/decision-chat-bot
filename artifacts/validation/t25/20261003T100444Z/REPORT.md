# 중단된 T25 예열 시도

이 실행은 본 측정 시작 직후 입력 생성 결함을 확인해 중단했다. `pdf_near`의 실제 PDF 추출 텍스트가 24,000자여서 지원 범위 20,000자를 넘었고 유효 요청 구성 비율을 왜곡할 수 있었다. 이 디렉터리의 journal·collector 자료는 진단용이며 G12 통과 증거로 사용하지 않는다.

입력 생성기를 수정하고 제품 파서로 모든 종류를 사전 검사했다. 수정 후 `text_near` 19,950자, `pdf_near` 합계 18,178자와 파일 5,430,730바이트, `docx_near` 합계 16,988자, `md_near` 합계 7,605자였다. 새 전용 환경에서 5분 예열과 30분 본 측정을 다시 시작했다.
