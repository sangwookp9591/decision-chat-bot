1. **G10:** 실제 브라우저 에이전트(지원 브라우저의 에이전트 호출 주체)에서 도구 1회 호출 증거가 필요하다.

3. **G13:** 운영 배포, 운영 인증 공급자, 원격 관측·알림 수신, 보존·삭제 정책 확정 후 30일 관측이 필요하다.
4. 백업·복원 실증에는 업무·규칙 버전 데이터가 포함되지 않았다(`t26/README.md`).

6. npm 감사 경고 7건(중간 5, 높음 1, 치명 1)이 있다 — 의존성 점검이 필요하다(`t01-rerun`).
7. 부하 시험 공식 결과의 SSE 전달 p95는 경계값(2,000ms)이다. 개선 후 보조 10분 측정은 275ms이며, 공식 30분 재측정은 하지 않았다.
