# 다른 화면의 기본 HTML 모양 점검 (보고만, 수정 없음)

방법: 전용 환경(API 9391·vite 6691, tenant `t-uxe`)에서 화면별 역할 계정으로 1440px·375px 전체 스크린샷(`other/<화면>-<폭>.png`)을 찍어 눈으로 확인. 요청 접수는 CHAT-1 진행 중이라 제외. 모든 화면에서 375px 가로 넘침은 0.

## 공통 관찰
- 앱 공용 `Button` 구성요소를 쓰지 않고 `<button>`을 그대로 쓴 화면(검토 대기·업무)에서 기본 회색 버튼이 남음.
- `<select>`·체크박스는 전용 스타일 토큰이 없어 화면마다 모양이 다름(공용 Select/Field 구성요소 부재). 평가 라벨 화면은 칩·세그먼트로 대체했으며, 공용 필드 구성요소는 추가하지 않음.
- 우선순위 제안: 정책(표 잘림·영문 키 라벨) → 업무(새로고침 버튼) → 검토 대기 → 실행 관찰.
